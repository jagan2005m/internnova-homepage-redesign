# InternNova Homepage Redesign

A responsive, portfolio-ready homepage concept built with **HTML, CSS, and vanilla JavaScript**.

## Files
- `index.html` — complete homepage structure and page content
- `style.css` — design system, responsive layouts, cards, animations, and mobile styles
- `script.js` — mobile menu, scroll reveals, domain selector, FAQ accordion, testimonial demo slider, and newsletter demo
- `README.md` — setup and deployment notes

## Run locally
1. Extract the ZIP file.
2. Open the `InternNova_Redesign` folder.
3. Double-click `index.html` to open it in your browser.
4. For a smoother development workflow, open the folder in VS Code and use the Live Server extension.

No npm install or build step is required. Google Fonts are loaded from the internet; the site still uses fallback fonts if they are unavailable.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `internnova-homepage-redesign`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment source, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site and open the URL it provides.

You can also deploy the folder through Vercel as a static site. No build command is needed; use the project root as the output directory if prompted.

## Important before submission
- This is an independent redesign concept, not an official InternNova site.
- Program labels and sections are inspired by publicly listed InternNova content, but confirm every current program detail before publishing.
- The statistics are labelled for verification and should be confirmed by the company before public use.
- Testimonials are illustrative placeholders, not genuine student reviews. Replace them with approved, real feedback or remove that section before publishing.
- The newsletter is a front-end demo only. It does not collect, store, or send email addresses. Connect an approved mailing provider/backend before production.
- Official-program links currently point to `https://internnova.co.in/`. Verify the correct target URL and application pages with the company before final submission.
- Use the redesign as a concept and do not imply company endorsement unless you receive permission.
